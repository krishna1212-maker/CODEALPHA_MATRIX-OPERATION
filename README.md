# Matrix Operations in C

A modular C program that performs **Matrix Addition**, **Matrix Multiplication**, and **Matrix Transpose** using functions and 2D arrays.

---

## Features

- Input any matrix up to 10×10
- Matrix Addition (with dimension validation)
- Matrix Multiplication (with compatibility check)
- Transpose of Matrix A or B
- Clean formatted output
- Error handling for invalid dimensions and wrong input

---

## How to Compile and Run

### On Windows (using GCC / MinGW)
```bash
gcc matrix.c -o matrix
matrix.exe
```

### On Linux / Mac
```bash
gcc matrix.c -o matrix
./matrix
```
